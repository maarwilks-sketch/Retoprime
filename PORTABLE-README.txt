RETOPRIME - portable preview

Extract the entire ZIP into a folder before opening RETOPRIME.exe.
Keep the engine, plugins and DLL files alongside the application.
No Blender or Python installation is required.

1. Open an OBJ or FBX mesh.
2. Choose a target face count and whether to preserve sharp features.
3. Select Generate quad mesh. Cancel stops the operation.
4. Inspect the result: drag to rotate and scroll to zoom.
5. Select Save result as OBJ.

This is an early working preview, not the completed modelling suite.
It processes geometry only. UVs, textures and materials are not preserved.
Target face count is approximate. Highly complex or damaged input may fail.
The wire preview samples large meshes for responsiveness; the engine and
exporter use the full mesh. UV tools, manual retopology and sculpting are
not part of this preview.
